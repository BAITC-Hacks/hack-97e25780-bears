# HackAlem AI MVP

## Команда
- Участник 2: backend / AI integration

## Описание
Минимальный MVP для платформы геймификации практических заданий. Сервис принимает описание бизнес-задачи, оценивает её и возвращает рекомендации по практическим заданиям для студентов.

## Основной сценарий
Пользователь описывает бизнес-проблему или задачу, а система рекомендует набор практических заданий, их уровень сложности, полезность и пояснение, почему они подходят.

## Технологии
- Node.js
- Express
- OpenAI API
- dotenv

## Установка
```bash
npm install
```

## Переменные окружения
Скопируйте `.env.example` в `.env` и заполните значения:

```bash
cp .env.example .env
```

```env
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4o-mini
PORT=3000
```

## Запуск
```bash
npm run dev
```

или

```bash
npm start
```

## Проверка
```bash
curl http://localhost:3000/health
```

## API
### GET /health
Проверка статуса сервиса.

### POST /api/recommend-tasks
Принимает JSON:

```json
{
  "businessProblem": "Нужно снизить время обработки заявок в отделе продаж",
  "audience": "студенты",
  "taskCount": 3,
  "context": "Для малого бизнеса"
}
```

Возвращает рекомендации по заданиям и краткое объяснение.

## Ограничения MVP
- нет базы данных;
- нет авторизации;
- нет UI;
- AI использует внешнюю модель через OpenAI API;
- работа зависит от корректно настроенного `OPENAI_API_KEY`.

## Использование AI
В проекте используется OpenAI API через модель `gpt-4o-mini` для генерации рекомендаций по заданиям на основе бизнес-контекста.
