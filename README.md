# AI Sana Challenge Hub

Платформа превращает короткий черновик бизнес-задачи в понятную карточку,
показывает прозрачный рейтинг готовности и позволяет студенческим командам
откликаться. Решение о выборе команды всегда принимает представитель бизнеса.

## Продуктовые материалы

- [Продуктовый контракт](docs/product-spec.md) — сценарий, поля, статусы,
  рейтинг и контракт AI-функции.
- [Демонстрационный сценарий](docs/demo-scenario.md) — эталонный путь для
  пятиминутного показа.
- [Критерии приёмки MVP](docs/acceptance-checklist.md) — единая проверка
  готовности frontend и backend.
- [Демонстрационные данные](data/demo-seed.json) — пять черновиков, карточек,
  команд и откликов.

## Границы MVP

В MVP входят конструктор задачи, минимум три уточняющих вопроса, редактируемая
карточка, рейтинг 0–100, каталог, отклик команды и ручной выбор бизнеса.
Авторизация, чат, уведомления, календарь, файловое хранилище, мобильная версия,
собственная ML-модель и автоматический выбор команды не входят в MVP.
