# Документация StartCard.ai

Начните с [общего README](../README.md): там описаны текущие возможности, установка и ограничения.

| Задача | Документ |
|---|---|
| Запустить приложение и пройти демо | [README → проверка](../README.md#проверка-для-команды-и-жюри) |
| Понять расположение кода и хранение данных | [Архитектура](architecture.md) |
| Подключить клиент или проверить запрос | [Контракт API](api-contract.md) |
| Подготовить показ основного сценария | [Демо-сценарий](demo-scenario.md) |
| Сверить исходные продуктовые решения | [Продуктовый контракт](product-spec.md) |
| Проверить требования к MVP | [Чек-лист приёмки](acceptance-checklist.md) |
| Внести изменение в командный репозиторий | [Участие в разработке](../CONTRIBUTING.md) |

`product-spec.md` сохраняет исходную схему общего API и его формулу рейтинга. Актуальная схема интерфейса, профилей и уведомлений описана в `api-contract.md`. Примеры в [demo-seed.json](../data/demo-seed.json) — учебные данные, не реальные заказчики.

Изображения оформления находятся в [assets/](assets/). Пользовательские данные создаются при запуске в `data/runtime/` и не должны попадать в Git.
